# CSS Meme Slider

Pure CSS Meme Slider.
A fully functional image slider built with only HTML and CSS (zero JavaScript).

## Deploy

[Live Demo](https://alexander-domanov.github.io/cssMemeSlider/cssMemeSlider/index.html)

## Tech Stack

- HTML5
- CSS3 (Flexbox, transitions)
- Radio buttons for state control

---

## Features

- CSS-only slider (no JavaScript)
- Smooth slide transition using `transform`
- Synchronized captions and images
- Interactive navigation dots (hover / active states)
- Responsive design for mobile and desktop

---

## Notes

- No frameworks used
- No preprocessors
- Fully pure CSS implementation
